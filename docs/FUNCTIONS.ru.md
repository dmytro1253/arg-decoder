## Специальные ноды

Ноды со своим интерфейсом: ввод, результаты, авто-поиск, картинки, звук, файлы.

### Специальные ноды · Ввод и вывод

#### Ввод `input`

Сюда вставляется шифр. Можно сделать несколько вводов для частей и ключей.

- Входы: нет
- Параметры:
  - Текст

#### Результат `view`

Крупно показывает значение, распознаёт ссылки и YouTube ID.

- Входы: вход

#### Заметка `note`

Свободный текст для гипотез и подсказок.

- Входы: нет

#### Артефакт (файл) `artifact`

Улика-файл: картинка, звук, видео, архив, лог. Перетащи файл на холст, вставь Ctrl+V или выбери кнопкой. Оригинал хранится без изменений.

- Входы: нет

### Специальные ноды · Авто

#### Авто-расшифровка `auto`

Перебирает цепочки известных приёмов и показывает лучшие результаты (профиль расследования и ключи проекта учитываются). Клик по результату — выбрать, «В граф» — развернуть цепочку нодами. Если убедительного результата нет, нода так и скажет.

- Входы: вход
- Параметры:
  - Глубина — варианты: Быстро (2 шага), **Обычно (3 шага)**, Глубоко (4 шага)

#### Автоподбор Виженера `vigcrack`

Встроенный подбор Виженера без подсказок: короткий текст — полный перебор коротких ключей + словарь, длинный — частотный анализ с итерированным локальным поиском. Ключи вашего проекта проверяются напрямую и всегда остаются в списке. Все варианты алфавита сразу.

- Входы: вход
- Параметры:
  - Движок — варианты: **Авто: Python, если доступен**, Python (полные словари, CUDA), Браузер (без установки)
  - Стратегия (Python) — варианты: **Авто по длине текста**, Полный перебор, Частотный анализ, Словарь (все слова), Восхождение на холм
  - Шифр — варианты: **Виженер**, Бофор, Вариант Бофора, Все три (браузер)
  - Язык (Python) — варианты: **Авто**, Русский, Украинский, Английский
  - Алфавит (браузер) — варианты: **Авто (по тексту)**, en-26, ru-33 (с Ё), ru-32 (без Ё)
  - Макс. длина ключа (0 = авто) — по умолчанию: `0`
  - Использовать видеокарту (CUDA) — по умолчанию: вкл
  - Глубокий перебор в браузере (до 5 букв) — по умолчанию: выкл

### Специальные ноды · Проверка

#### Анализ строки `analyze`

Длина, алфавит, индекс совпадений, на что похоже. Пропускает значение дальше.

- Входы: вход

#### Проверка YouTube `youtube`

Проверяет ID через YouTube oEmbed: есть ли видео, название и канал. Нужен запуск через Запуск.bat.

- Входы: вход
- Параметры:
  - Проверять автоматически — по умолчанию: вкл

#### Перебор маски ID `mask`

Пропуски «_» или «?» заполняются символами из набора, каждый вариант проверяется через YouTube. Пример: _y_xPVyp_H_.

- Входы: маска
- Параметры:
  - Маска (если вход не подключён) — по умолчанию: `?y?xPVyp8H0`
  - Символы-пропуски — по умолчанию: `_?`
  - Набор — варианты: **Все символы ID (64)**, Буквы и цифры (62), a–z, A–Z, 0–9, Свой
  - Свой набор
  - Остановиться на первой находке — по умолчанию: вкл

#### Поиск ссылок `links`

Находит ссылки (и «обезвреженные» hxxp, [.], перевёрнутые) и ID, похожие на YouTube, Drive, Catbox, Pastebin, Imgur… Выход — первая найденная ссылка.

- Входы: вход
- Параметры:
  - Показывать слабые совпадения — по умолчанию: выкл

### Специальные ноды · Изображения

#### Биты → картинка `bits_to_image`

Строки из 0 и 1 (или своих символов) становятся картинкой-артефактом: ширина, порядок (по строкам или столбцам), отражения, инверсия, масштаб и белые поля. Дальше подключается «QR и штрих-коды», OCR или обработка.

- Входы: биты
- Параметры:
  - Ширина в клетках (0 — по строкам или квадрат) — по умолчанию: `0`
  - Символ «чёрной» клетки — по умолчанию: `1`
  - Символ «белой» клетки — по умолчанию: `0`
  - Порядок — варианты: **по строкам**, по столбцам (транспонировать)
  - Отразить по горизонтали — по умолчанию: выкл
  - Отразить по вертикали — по умолчанию: выкл
  - Инвертировать — по умолчанию: выкл
  - Пикселей на клетку — по умолчанию: `8`
  - Белое поле, клеток (для QR нужно 4) — по умолчанию: `4`

#### Изображение: тона и цвет `img_adjust`

Яркость, контраст, гамма, уровни, поднятие теней («высветлить»), автоуровни, инверсия, оттенки серого, порог, канал R/G/B/A. Порядок: канал → серый → уровни → тени → гамма → яркость/контраст → авто → инверсия → порог. «До/после» сравнивает с исходником. Оригинал не меняется.

- Входы: изображение
- Параметры:
  - Канал — варианты: **все**, R, G, B, Alpha, яркость
  - Оттенки серого — по умолчанию: выкл
  - Чёрная точка, 0–254 — 0…254, по умолчанию 0
  - Белая точка, 1–255 — 1…255, по умолчанию 255
  - Поднять тени, % — 0…100 %, по умолчанию 0
  - Гамма, 0.1–5 — 0.1…5, по умолчанию 1
  - Яркость, −255…255 — -255…255, по умолчанию 0
  - Контраст, −100…100 — -100…100, по умолчанию 0
  - Авто — варианты: **нет**, автоуровни, автоуровни по каналам, выравнивание гистограммы
  - Инвертировать — по умолчанию: выкл
  - Порог — варианты: **нет**, фиксированный, Отсу (авто)
  - Уровень порога, 0–255 — 0…255, по умолчанию 128

#### Изображение: обрезка и поворот `img_geom`

Обрезка по области (кнопка «Область» и перетаскивание по картинке), поворот на 90/180/270°, отражения, увеличение без сглаживания. Порядок: обрезка → поворот → отражение → масштаб. Кнопка «Результат» показывает итог.

- Входы: изображение
- Параметры:
  - Поворот — варианты: **0°**, 90° →, 180°, 270° (90° ←)
  - Отразить по горизонтали — по умолчанию: выкл
  - Отразить по вертикали — по умолчанию: выкл
  - Увеличить в … раз — 0.1…16 ×, по умолчанию 1

#### Изображение: битовая плоскость `img_bits`

Показывает один бит выбранного канала как чёрно-белую картинку (бит 0 — младший). Так ищут скрытые узоры, спрятанные в младших битах (стеганография LSB). Скрытые данные в JPEG после пересохранения теряются — берите исходный файл.

- Входы: изображение
- Параметры:
  - Канал — варианты: **R**, G, B, Alpha
  - Бит (0 — младший … 7) — 0…7, по умолчанию 0

#### Изображение: LSB-извлечение `img_lsb`

Собирает младшие биты пикселей в байты. Каналы (порядок обхода), число бит, порядок бит в байте, обход по строкам или столбцам, пропуск бит. Выход — строка latin1 (по символу на байт); подходит для Base64/hex/ASCII-текстов.

- Входы: изображение
- Параметры:
  - Каналы (r g b a в нужном порядке) — по умолчанию: `rgb`
  - Сколько младших бит, 1–8 — 1…8, по умолчанию 1
  - Порядок бит в байте — варианты: **старший первым (MSB)**, младший первым (LSB)
  - Обход — варианты: **по строкам**, по столбцам
  - Пропустить бит в начале — по умолчанию: `0`
  - Инвертировать биты — по умолчанию: выкл
  - Макс. байт на выходе (0 — все) — по умолчанию: `0`

#### Изображение: метаданные `img_meta`

Размер, формат, текстовые чанки PNG (tEXt/zTXt/iTXt), комментарии JPEG/GIF, EXIF-текст и данные, дописанные после конца изображения (с поиском сигнатур ZIP, PNG и др.). Выход — текстовый отчёт.

- Входы: изображение

#### Изображение: OCR (текст) `img_ocr`

Распознаёт текст на картинке локально, без интернета, при запуске через локальный сервер. Порядок «авто»: шрифт Minecraft (цифры по сетке пикселей) → RapidOCR (ONNX, экспериментально; ставится командой python setup_ocr.py) как есть, затем с автоконтрастом → tesseract.js с перебором предобработок. Сырые ответы всех веток, рамки строк и убранные обрывки сохраняются; символы не исправляются (O не становится 0, Ґ не становится Г). Для больших скриншотов выдели область кнопкой «Область».

- Входы: изображение
- Параметры:
  - Движок — варианты: **авто (Minecraft → RapidOCR → tesseract)**, RapidOCR (экспериментально), tesseract.js, шрифт Minecraft (цифры)
  - Язык — варианты: **English**, Русский, Українська, English + Русский, Русский + English, Українська + English, EN + RU + UK
  - Только цифры — по умолчанию: выкл
  - Предобработка — варианты: **авто (перебор)**, как есть + увеличение, автоконтраст, автоконтраст + сглаживание, поднять тени (тёмные кадры), чёрно-белое, инверсия

#### Изображение: QR / штрих-код `img_qr`

Читает QR-коды (jsQR, локально); другие штрих-коды — если браузер поддерживает BarcodeDetector (кнопка «Другие коды»). Перебирает инверсию, автоуровни и масштаб; найденный код обводится на картинке. Для QR на большом кадре выдели область.

- Входы: изображение

#### Изображение: SGA (стол зачарований) `img_sga`

Читает «галактический» шрифт Minecraft: бинаризация по цвету → строки → сетка пикселей шрифта → подбор шаблонов (составные знаки тоже). Выдаёт латинские буквы клавиш; знаки, не совпавшие с шаблоном, дают «?». Если автор набирал русский текст в латинской раскладке (gjl[jlbn = подходит), включи «Выход: кириллица». На картинке — рамки глифов: зелёные уверенные, жёлтые по непроверенным шаблонам, красные не распознаны.

- Входы: изображение
- Параметры:
  - Порог яркости, 0–255 (0 — авто) — 0…255, по умолчанию 0
  - Пикселей на «пиксель шрифта» (0 — авто) — 0…64 px, по умолчанию 0
  - Выход — варианты: **латиница (буквы клавиш)**, кириллица (раскладка ЙЦУКЕН)

#### Изображение: две картинки → одна `img_combine`

Накладывает картинку B на A: разность, XOR, сумма, умножение, «экран», среднее или прозрачность. Сдвиг B (dx, dy) выравнивает картинки; «растянуть» подгоняет B под размер A. Разность и XOR проявляют то, чем две почти одинаковые картинки отличаются.

- Входы: картинка A, картинка B
- Параметры:
  - Как смешать — варианты: **разность \|A − B\|**, XOR байтов, сумма, A − B, умножение, экран, среднее, B поверх A с прозрачностью
  - Прозрачность B, % (для «поверх») — 0…100 %, по умолчанию 50
  - Сдвиг B по X, px — по умолчанию: `0`
  - Сдвиг B по Y, px — по умолчанию: `0`
  - Растянуть B до размера A — по умолчанию: выкл

### Специальные ноды · Звук и видео

#### Спектрограмма (аудио/видео) `spectrogram`

Спектрограмма и осциллограмма звука: размер БПФ, окно, перекрытие, диапазон частот и дБ, линейная/лог шкала, палитры, контраст. Тяни мышью — выделение, колесо — зум по времени. Выход — картинка-артефакт (слова в спектрограмме читает OCR) или WAV-фрагмент. Для OldRoot/Endermite: слово рисуют частоты, ищи его при размере БПФ 1024–4096 и логарифмической шкале.

- Входы: аудио/видео
- Параметры:
  - Размер БПФ — варианты: 256, 512, 1024, **2048**, 4096, 8192
  - Окно — варианты: **Hann**, Hamming, Blackman
  - Перекрытие кадров, % — варианты: 0, 50, **75**, 87.5, 93.75
  - Канал — варианты: **Моно (L+R)**, Левый, Правый, Разность L−R
  - Развернуть звук (reverse) — по умолчанию: выкл
  - Скорость (1 = как есть; 0.5 = вдвое медленнее и ниже) — 0.1…4 ×, по умолчанию 1
  - Мин. частота, Гц — по умолчанию: `0`
  - Макс. частота, Гц (0 = до Найквиста) — по умолчанию: `0`
  - Шкала частот — варианты: **Линейная**, Логарифмическая
  - Палитра — варианты: **Inferno**, Magma, Viridis, Жар, Лёд, Серая, Серая (тёмное на светлом, для OCR)
  - Автоуровни по данным — по умолчанию: вкл
  - Динамический диапазон при автоуровнях — 10…160 дБ, по умолчанию 80
  - Низ шкалы (если автоуровни выключены) — -200…0 дБ, по умолчанию -100
  - Верх шкалы (если автоуровни выключены) — -120…20 дБ, по умолчанию -10
  - Контраст (гамма): >1 затемняет слабое, <1 поднимает — 0.1…4, по умолчанию 1
  - Показывать осциллограмму — по умолчанию: вкл
  - Что отдавать на выход — варианты: **Картинка-артефакт (спектрограмма выделения)**, Звук-артефакт (WAV выделения)
  - Высота экспортной картинки, px — варианты: 256, **512**, 1024, 2048

#### Морзе из звука `morse_audio`

Находит тон (сам или на заданной частоте), порог, длину точки и выдаёт точки/тире (для ноды «Морзе → текст») либо готовый текст. Сомнительные элементы подсвечены на графике; в тексте их можно пометить {X} и ¦.

- Входы: аудио/видео
- Параметры:
  - Канал — варианты: **Моно (L+R)**, Левый, Правый, Разность L−R
  - С секунды (0 = с начала) — по умолчанию: `0`
  - По секунду (0 = до конца) — по умолчанию: `0`
  - Частота тона, Гц (0 = найти сам) — по умолчанию: `0`
  - Порог от максимума, 0–1 (0 = автоматически) — 0…1, по умолчанию 0
  - Длина точки (0 = оценить) — 0…2000 мс, по умолчанию 0
  - Алфавит — варианты: **Латиница**, Кириллица
  - Выход — варианты: **Точки и тире**, Текст, Отчёт
  - Помечать неуверенные места (? в Морзе, {X} и ¦ в тексте) — по умолчанию: выкл

#### DTMF из звука `dtmf_audio`

Телефонные тоны (Гёрцель на 8 частотах) → цифры 0–9, *, #, A–D. Выход можно подать на «Телефон: нажатия → буквы». Паузы длиннее заданной превращаются в пробелы (удобно для мультитапа).

- Входы: аудио/видео
- Параметры:
  - Канал — варианты: **Моно (L+R)**, Левый, Правый, Разность L−R
  - С секунды (0 = с начала) — по умолчанию: `0`
  - По секунду (0 = до конца) — по умолчанию: `0`
  - Окно анализа — 5…200 мс, по умолчанию 30
  - Мин. длительность тона — 5…500 мс, по умолчанию 40
  - Мин. амплитуда, 0–1 — 0…1, по умолчанию 0.01
  - Пауза → пробел, мс (0 = не делить) — по умолчанию: `0`
  - Выход — варианты: **Цифры**, Отчёт по тонам

#### SSTV из звука `sstv_audio`

- Входы: вход
- Параметры:
  - План (JSON) — по умолчанию: `[]`

### Операции (ноды-функции) · Хеши

#### Хеш MD5 `hash_md5`

MD5 (128 бит). Не для безопасности — но так часто «прячут» пароли и ответы в ARG. Для файла-артефакта хешируются его байты. Между символами и байтами выбирай кодировку явно.

- Входы: вход
- Параметры:
  - Кодировка текста — варианты: **UTF-8**, CP1251 (Windows), Байты как есть (latin1)
  - Убрать пробелы по краям — по умолчанию: выкл
  - Заглавные hex — по умолчанию: выкл

#### Хеш SHA-1 `hash_sha1`

SHA-1 (160 бит) текста или файла. Между символами и байтами выбирай кодировку явно.

- Входы: вход
- Параметры:
  - Кодировка текста — варианты: **UTF-8**, CP1251 (Windows), Байты как есть (latin1)
  - Убрать пробелы по краям — по умолчанию: выкл
  - Заглавные hex — по умолчанию: выкл

#### Хеш SHA-256 `hash_sha256`

SHA-256 (256 бит) текста или файла. Между символами и байтами выбирай кодировку явно.

- Входы: вход
- Параметры:
  - Кодировка текста — варианты: **UTF-8**, CP1251 (Windows), Байты как есть (latin1)
  - Убрать пробелы по краям — по умолчанию: выкл
  - Заглавные hex — по умолчанию: выкл

#### Хеш SHA-512 `hash_sha512`

SHA-512 (512 бит) текста или файла. Между символами и байтами выбирай кодировку явно.

- Входы: вход
- Параметры:
  - Кодировка текста — варианты: **UTF-8**, CP1251 (Windows), Байты как есть (latin1)

#### Хеш CRC32 `hash_crc32`

CRC32 (32 бита, контрольная сумма zip/png) текста или файла. Между символами и байтами выбирай кодировку явно.

- Входы: вход
- Параметры:
  - Кодировка текста — варианты: **UTF-8**, CP1251 (Windows), Байты как есть (latin1)
  - Убрать пробелы по краям — по умолчанию: выкл
  - Заглавные hex — по умолчанию: выкл

#### Все хеши `hash_all`

MD5, SHA-1, SHA-256, SHA-512 и CRC32 одной таблицей.

- Входы: вход
- Параметры:
  - Кодировка текста — варианты: **UTF-8**, CP1251 (Windows), Байты как есть (latin1)
  - Убрать пробелы по краям — по умолчанию: выкл
  - Заглавные hex — по умолчанию: выкл

#### Проверка хеша `hash_check`

Совпадает ли хеш кандидата(ов) (по строке на вход) с данным дайджестом. Алгоритм определяется по длине: 8=CRC32, 32=MD5, 40=SHA-1, 64=SHA-256, 128=SHA-512. Дайджест — со второго входа или из параметра.

- Входы: кандидаты, дайджест
- Параметры:
  - Дайджест (если нет второго входа)
  - Алгоритм — варианты: **По длине**, MD5, SHA-1, SHA-256, SHA-512, CRC32
  - Кодировка текста — варианты: **UTF-8**, CP1251 (Windows), Байты как есть (latin1)
  - Каждая строка — отдельный кандидат — по умолчанию: вкл
  - Пробовать и без пробелов по краям — по умолчанию: вкл
  - Результат — варианты: **Отчёт**, Совпавший кандидат (или ошибка)

#### Что это за хеш? `hash_identify`

Объясняет, чем может быть hex/Base64-строка по длине: MD5, NTLM, SHA-1… или просто токен. Хеши проверяются кандидатом, а не расшифровываются.

- Входы: вход

## Экранные клавиатуры

Кнопка **⌨ Клавиатуры** открывает плавающую панель: знаки вставляются в поле с фокусом или в её черновик.

- **Стол зачарований (SGA)** — В SGA нет регистра: «A» и «a» дают один знак, при обратном переводе получится строчная буква.
- **Шрифт Брайля** — Ячейка = 6 точек (1–3 слева, 4–6 справа). Подпись: английская/русская буква. Собери ячейку по точкам с фото в конструкторе ниже.
- **Азбука Морзе** — Буквы разделяются пробелом, слова — « / ». Клавиша буквы вставляет её код и пробел.
- **Руны** — ᚦ = th, ᛜ = ng, ᛇ = ï; ᛫ — разделитель слов (читается как пробел). Общие руны одинаковы в обоих футарках.
- **Греческий алфавит** — Подпись — латинская транслитерация, как в операции «Греческие буквы ↔ латиница».
- **Пигпен (масонский шифр)** — Юникод-приближения фигур; точка · в конце знака — вариант с точкой (J–R, W–Z). Режим жетонов вставляет rb, lrb. …
- **Спецсимволы и коды** — Невидимые символы подписаны, но в поле остаются невидимыми: проверяй длину текста или HEX-вид. Backspace стирает «§a» целиком.
- **Похожие буквы: кириллица ↔ латиница** — Клавиша вставляет двойник (он на кнопке), подпись — оригинал. Так прячут и находят «латинские» слова с кириллицей внутри.
