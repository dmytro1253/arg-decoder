## Спеціальні вузли

Вузли з власним інтерфейсом: введення, результати, автопошук, зображення, звук, файли.

### Спеціальні вузли · Ввід і вивід

#### Введення `input`

Сюди вставляється шифр. Можна зробити кілька введень для частин і ключів.

- Входи: немає
- Параметри:
  - Текст

#### Результат `view`

Крупно показує значення, розпізнає посилання й YouTube ID.

- Входи: вхід

#### Нотатка `note`

Вільний текст для гіпотез і підказок.

- Входи: немає

#### Артефакт (файл) `artifact`

Доказ-файл: зображення, звук, відео, архів, лог. Перетягни файл на полотно, встав через Ctrl+V або вибери кнопкою. Оригінал зберігається без змін.

- Входи: немає

### Спеціальні вузли · Авто

#### Авторозшифрування `auto`

Перебирає ланцюжки відомих прийомів і показує найкращі результати (профіль розслідування та ключі проєкту враховуються). Клік по результату — вибрати, «У граф» — розгорнути ланцюжок вузлами. Якщо переконливого результату немає, вузол так і скаже.

- Входи: вхід
- Параметри:
  - Глибина — варіанти: Швидко (2 кроки), **Звичайно (3 кроки)**, Глибоко (4 кроки)

#### Автопідбір Віженера `vigcrack`

Вбудований підбір Віженера без підказок: короткий текст — повний перебір коротких ключів + словник, довгий — частотний аналіз з ітерованим локальним пошуком. Ключі вашого проєкту перевіряються напряму й завжди залишаються в списку. Усі варіанти алфавіту одразу.

- Входи: вхід
- Параметри:
  - Рушій — варіанти: **Авто: Python, якщо доступний**, Python (повні словники, CUDA), Браузер (без встановлення)
  - Стратегія (Python) — варіанти: **Авто за довжиною тексту**, Повний перебір, Частотний аналіз, Словник (усі слова), Сходження на пагорб
  - Шифр — варіанти: **Віженер**, Бофор, Варіант Бофора, Усі три (браузер)
  - Мова (Python) — варіанти: **Авто**, Російська, Українська, Англійська
  - Алфавіт (браузер) — варіанти: **Авто (за текстом)**, en-26, ru-33 (з Ё), ru-32 (без Ё)
  - Макс. довжина ключа (0 = авто) — за замовчуванням: `0`
  - Використовувати відеокарту (CUDA) — за замовчуванням: увімк.
  - Глибокий перебір у браузері (до 5 літер) — за замовчуванням: вимк.

### Спеціальні вузли · Перевірка

#### Аналіз рядка `analyze`

Довжина, алфавіт, індекс збігів, на що схоже. Пропускає значення далі.

- Входи: вхід

#### Перевірка YouTube `youtube`

Перевіряє ID через YouTube oEmbed: чи є відео, назву та канал. Потрібен запуск через Запуск.bat.

- Входи: вхід
- Параметри:
  - Перевіряти автоматично — за замовчуванням: увімк.

#### Перебір маски ID `mask`

Пропуски «_» або «?» заповнюються символами з набору, кожен варіант перевіряється через YouTube. Приклад: _y_xPVyp_H_.

- Входи: маска
- Параметри:
  - Маска (якщо вхід не підключено) — за замовчуванням: `?y?xPVyp8H0`
  - Символи-пропуски — за замовчуванням: `_?`
  - Набір — варіанти: **Усі символи ID (64)**, Літери й цифри (62), a–z, A–Z, 0–9, Свій
  - Свій набір
  - Зупинитися на першій знахідці — за замовчуванням: увімк.

#### Пошук посилань `links`

Знаходить посилання (і «знешкоджені» hxxp, [.], перевернуті) та ID, схожі на YouTube, Drive, Catbox, Pastebin, Imgur… Вихід — перше знайдене посилання.

- Входи: вхід
- Параметри:
  - Показувати слабкі збіги — за замовчуванням: вимк.

### Спеціальні вузли · Зображення

#### Біти → картинка `bits_to_image`

Рядки з 0 та 1 (або власних символів) стають картинкою-артефактом: ширина, порядок (за рядками чи стовпцями), відображення, інверсія, масштаб і білі поля. Далі підключається «QR і штрихкоди», OCR або обробка.

- Входи: біти
- Параметри:
  - Ширина в клітинках (0 — за рядками або квадрат) — за замовчуванням: `0`
  - Символ «чорної» клітинки — за замовчуванням: `1`
  - Символ «білої» клітинки — за замовчуванням: `0`
  - Порядок — варіанти: **за рядками**, за стовпцями (транспонувати)
  - Відобразити по горизонталі — за замовчуванням: вимк.
  - Відобразити по вертикалі — за замовчуванням: вимк.
  - Інвертувати — за замовчуванням: вимк.
  - Пікселів на клітинку — за замовчуванням: `8`
  - Біле поле, клітинок (для QR потрібно 4) — за замовчуванням: `4`

#### Зображення: тони й колір `img_adjust`

Яскравість, контраст, гамма, рівні, підняття тіней («висвітлити»), авторівні, інверсія, відтінки сірого, поріг, канал R/G/B/A. Порядок: канал → сірий → рівні → тіні → гамма → яскравість/контраст → авто → інверсія → поріг. «До/після» порівнює з вихідним зображенням. Оригінал не змінюється.

- Входи: зображення
- Параметри:
  - Канал — варіанти: **усі**, R, G, B, Alpha, яскравість
  - Відтінки сірого — за замовчуванням: вимк.
  - Чорна точка, 0–254 — 0…254, за замовчуванням 0
  - Біла точка, 1–255 — 1…255, за замовчуванням 255
  - Підняти тіні, % — 0…100 %, за замовчуванням 0
  - Гамма, 0.1–5 — 0.1…5, за замовчуванням 1
  - Яскравість, −255…255 — -255…255, за замовчуванням 0
  - Контраст, −100…100 — -100…100, за замовчуванням 0
  - Авто — варіанти: **немає**, авторівні, авторівні по каналах, вирівнювання гістограми
  - Інвертувати — за замовчуванням: вимк.
  - Поріг — варіанти: **немає**, фіксований, Оцу (авто)
  - Рівень порогу, 0–255 — 0…255, за замовчуванням 128

#### Зображення: обрізання й поворот `img_geom`

Обрізання за областю (кнопка «Область» і перетягування по картинці), поворот на 90/180/270°, відображення, збільшення без згладжування. Порядок: обрізання → поворот → відображення → масштаб. Кнопка «Результат» показує підсумок.

- Входи: зображення
- Параметри:
  - Поворот — варіанти: **0°**, 90° →, 180°, 270° (90° ←)
  - Відобразити по горизонталі — за замовчуванням: вимк.
  - Відобразити по вертикалі — за замовчуванням: вимк.
  - Збільшити в … разів — 0.1…16 ×, за замовчуванням 1

#### Зображення: бітова площина `img_bits`

Показує один біт вибраного каналу як чорно-білу картинку (біт 0 — молодший). Так шукають приховані візерунки, сховані в молодших бітах (стеганографія LSB). Приховані дані в JPEG після повторного збереження втрачаються — беріть вихідний файл.

- Входи: зображення
- Параметри:
  - Канал — варіанти: **R**, G, B, Alpha
  - Біт (0 — молодший … 7) — 0…7, за замовчуванням 0

#### Зображення: LSB-видобування `img_lsb`

Збирає молодші біти пікселів у байти. Канали (порядок обходу), кількість біт, порядок біт у байті, обхід за рядками або стовпцями, пропуск біт. Вихід — рядок latin1 (по символу на байт); підходить для Base64/hex/ASCII-текстів.

- Входи: зображення
- Параметри:
  - Канали (r g b a в потрібному порядку) — за замовчуванням: `rgb`
  - Скільки молодших біт, 1–8 — 1…8, за замовчуванням 1
  - Порядок біт у байті — варіанти: **старший першим (MSB)**, молодший першим (LSB)
  - Обхід — варіанти: **за рядками**, по стовпцях
  - Пропустити біти на початку — за замовчуванням: `0`
  - Інвертувати біти — за замовчуванням: вимк.
  - Макс. байтів на виході (0 — усі) — за замовчуванням: `0`

#### Зображення: метадані `img_meta`

Розмір, формат, текстові чанки PNG (tEXt/zTXt/iTXt), коментарі JPEG/GIF, EXIF-текст та дані, дописані після кінця зображення (з пошуком сигнатур ZIP, PNG тощо). Вихід — текстовий звіт.

- Входи: зображення

#### Зображення: OCR (текст) `img_ocr`

Розпізнає текст на зображенні локально, без інтернету, під час запуску через локальний сервер. Порядок «авто»: шрифт Minecraft (цифри за сіткою пікселів) → RapidOCR (ONNX; встановлюється разом із програмою) як є, потім з автоконтрастом → tesseract.js з перебором попередніх обробок. Сирі відповіді всіх гілок, рамки рядків і прибрані уривки зберігаються; символи не виправляються (O не стає 0, Ґ не стає Г). Для великих знімків екрана виділи область кнопкою «Область».

- Входи: зображення
- Параметри:
  - Рушій — варіанти: **авто (Minecraft → RapidOCR → tesseract)**, RapidOCR, tesseract.js, шрифт Minecraft (цифри)
  - Мова — варіанти: **English**, Русский, Українська, English + Русский, Русский + English, Українська + English, EN + RU + UK
  - Лише цифри — за замовчуванням: вимк.
  - Попередня обробка — варіанти: **авто (перебір)**, як є + збільшення, автоконтраст, автоконтраст + згладжування, підняти тіні (темні кадри), чорно-біле, інверсія
  - Рядки на виході — варіанти: **як на картинці**, склеїти в один (без пробілів), через пробіл

#### Зображення: QR / штрихкод `img_qr`

Читає QR-коди (jsQR, локально); інші штрихкоди — якщо браузер підтримує BarcodeDetector (кнопка «Інші коди»). Перебирає інверсію, авторівні та масштаб; знайдений код обводиться на картинці. Для QR на великому кадрі виділи область.

- Входи: зображення

#### Зображення: SGA (стіл зачарувань) `img_sga`

Читає «галактичний» шрифт Minecraft: бінаризація за кольором → рядки → сітка пікселів шрифту → підбір шаблонів (складені знаки теж). Видає латинські літери клавіш; знаки, що не збіглися з шаблоном, дають «?». Якщо автор набирав російський текст у латинській розкладці (gjl[jlbn = подходит), увімкни «Вихід: кирилиця». На картинці — рамки гліфів: зелені впевнені, жовті за неперевіреними шаблонами, червоні не розпізнані.

- Входи: зображення
- Параметри:
  - Поріг яскравості, 0–255 (0 — авто) — 0…255, за замовчуванням 0
  - Пікселів на «піксель шрифту» (0 — авто) — 0…64 px, за замовчуванням 0
  - Вихід — варіанти: **латиниця (літери клавіш)**, кирилиця (розкладка ЙЦУКЕН)

#### Зображення: дві картинки → одна `img_combine`

Накладає картинку B на A: різниця, XOR, сума, множення, «екран», середнє або прозорість. Зсув B (dx, dy) вирівнює картинки; «розтягнути» підганяє B під розмір A. Різниця та XOR виявляють те, чим дві майже однакові картинки відрізняються.

- Входи: картинка A, картинка B
- Параметри:
  - Як змішати — варіанти: **різниця \|A − B\|**, XOR байтів, сума, A − B, множення, екран, середнє, B поверх A з прозорістю
  - Прозорість B, % (для «поверх») — 0…100 %, за замовчуванням 50
  - Зсув B по X, px — за замовчуванням: `0`
  - Зсув B по Y, px — за замовчуванням: `0`
  - Розтягнути B до розміру A — за замовчуванням: вимк.

### Спеціальні вузли · Звук і відео

#### Спектрограма (аудіо/відео) `spectrogram`

Спектрограма й осцилограма звуку: розмір ШПФ, вікно, перекриття, діапазон частот і дБ, лінійна/лог шкала, палітри, контраст. Тягни мишею — виділення, колесо — зум за часом. Вихід — картинка-артефакт (слова в спектрограмі читає OCR) або WAV-фрагмент. Для OldRoot/Endermite: слово малюють частоти, шукай його за розміру ШПФ 1024–4096 і логарифмічної шкали.

- Входи: аудіо/відео
- Параметри:
  - Розмір ШПФ — варіанти: 256, 512, 1024, **2048**, 4096, 8192
  - Вікно — варіанти: **Hann**, Hamming, Blackman
  - Перекриття кадрів, % — варіанти: 0, 50, **75**, 87.5, 93.75
  - Канал — варіанти: **Моно (L+R)**, Лівий, Правий, Різниця L−R
  - Розгорнути звук (reverse) — за замовчуванням: вимк.
  - Швидкість (1 = як є; 0.5 = удвічі повільніше й нижче) — 0.1…4 ×, за замовчуванням 1
  - Мін. частота, Гц — за замовчуванням: `0`
  - Макс. частота, Гц (0 = до Найквіста) — за замовчуванням: `0`
  - Шкала частот — варіанти: **Лінійна**, Логарифмічна
  - Палітра — варіанти: **Inferno**, Magma, Viridis, Жар, Лёд, Серая, Серая (тёмное на светлом, для OCR)
  - Авторівні за даними — за замовчуванням: увімк.
  - Динамічний діапазон за авторівнів — 10…160 дБ, за замовчуванням 80
  - Низ шкали (якщо авторівні вимкнено) — -200…0 дБ, за замовчуванням -100
  - Верх шкали (якщо авторівні вимкнено) — -120…20 дБ, за замовчуванням -10
  - Контраст (гамма): >1 затемнює слабке, <1 піднімає — 0.1…4, за замовчуванням 1
  - Показувати осцилограму — за замовчуванням: увімк.
  - Що віддавати на вихід — варіанти: **Картинка-артефакт (спектрограма виділення)**, Звук-артефакт (WAV виділення)
  - Висота експортної картинки, px — варіанти: 256, **512**, 1024, 2048

#### Морзе зі звуку `morse_audio`

Знаходить тон (сам або на заданій частоті), поріг, довжину крапки й видає крапки/тире (для вузла «Морзе → текст») або готовий текст. Сумнівні елементи підсвічені на графіку; у тексті їх можна позначити {X} та ¦.

- Входи: аудіо/відео
- Параметри:

  - Дайджест (якщо немає другого входу)

  - Пробувати й без пробілів по краях — за замовчуванням: увімк.
  - Результат — варіанти: **Звіт**, Кандидат, що збігся (або помилка)

## Екранні клавіатури

Кнопка **⌨ Клавіатури** відкриває плаваючу панель: знаки вставляються в поле з фокусом або в її чернетку.

- **Стіл зачарувань (SGA)** — У SGA немає регістру: «A» і «a» дають один знак, при зворотному перекладі вийде мала літера.
- **Шрифт Брайля** — Комірка = 6 крапок (1–3 ліворуч, 4–6 праворуч). Підпис: англійська/російська літера. Збери комірку за крапками з фото в конструкторі нижче.
- **Абетка Морзе** — Літери розділяються пробілом, слова — « / ». Клавіша літери вставляє її код і пробіл.
- **Руни** — ᚦ = th, ᛜ = ng, ᛇ = ï; ᛫ — роздільник слів (читається як пробіл). Спільні руни однакові в обох футарках.
- **Грецький алфавіт** — Підпис — латинська транслітерація, як в операції «Грецькі літери ↔ латиниця».
- **Пігпен (масонський шифр)** — Юнікод-наближення фігур; крапка · в кінці знака — варіант із крапкою (J–R, W–Z). Режим жетонів вставляє rb, lrb. …
- **Спецсимволи та коди** — Невидимі символи підписані, але в полі лишаються невидимими: перевіряй довжину тексту або HEX-вигляд. Backspace стирає «§a» цілком.
- **Схожі літери: кирилиця ↔ латиниця** — Клавіша вставляє двійник (він на кнопці), підпис — оригінал. Так ховають і знаходять «латинські» слова з кирилицею всередині.
